# StayFinder – Hotel Booking App UI/UX Design
##  Project Overview
StayFinder is a modern and user-friendly hotel booking application UI/UX design created using Figma. The application helps users search for hotels, explore available rooms, compare prices, view hotel facilities, and book their preferred accommodation.The design focuses on a simple interface, clear navigation, and a smooth booking experience. It covers the complete user journey, from searching for a hotel to receiving booking confirmation.

## Objectives
- To design an attractive and easy-to-use hotel booking application.
- To help users search for hotels based on destination and travel dates.
- To display hotel details, room options, prices, ratings, and facilities.
- To simplify the room selection and guest information process.
- To provide a clear payment and booking confirmation flow.
- To improve user experience through consistent UI/UX design principles.
- To demonstrate the hotel booking journey through an interactive Figma prototype.

## Design Highlights

- **Modern UI:** Clean layouts with organized hotel cards and booking forms.
- **Color Palette:** Navy blue, white, and light grey for a professional appearance.
- **Typography:** Clear and readable fonts for better usability.
- **Hotel Cards:** Display hotel images, names, ratings, locations, and prices.
- **Reusable Components:** Consistent buttons, input fields, icons, and navigation bars.
- **Visual Hierarchy:** Important details and booking actions are easy to identify.
- **Mobile-First Design:** Designed for a mobile screen size of 390 × 844 px.
- **Consistent Layout:** Maintains the same visual style across all ten screens.
- **Interactive Prototype:** Connects screens to demonstrate the booking flow.

## Features
- **Splash Screen:** Introduces the StayFinder application.
- **Login / Sign Up:** Allows users to access or create an account.
- **Home / Search:** Provides destination, check-in, check-out, and guest selection.
- **Hotel Listings:** Displays available hotels with prices and ratings.
- **Hotel Details:** Shows hotel information, facilities, reviews, and room options.
- **Room Booking:** Collects guest details and stay information.
- **Payment Method:** Displays payment options such as UPI, cards, and net banking.
- **Booking Confirmation:** Shows successful booking details and total payment.
- **My Bookings:** Displays upcoming, past, and cancelled bookings.
- **Profile / Settings:** Provides access to user details, saved hotels, payment methods, and settings.
